# obsidian-doodle-blocks

obsidian-doodle-blocks 是一个面向 Obsidian 的主题项目。

当前设计方向来自已确认的 B 原型：遵循 Obsidian 原生的连续工作区布局，并将“纸质积木卡通”视觉语言应用到按钮、状态和设置界面。Q 原型用于设置界面的视觉参考。

## 原型

原型文件保存在本地 `prototypes/` 目录，不纳入版本控制。这轮原型包含 B 连续工作区、D/E/F 卡片备选、P/Q/R 交互效果，以及 Q 设置界面；设计记录和预览截图也保存在该目录。

本机存在原型文件时，在项目根目录运行 `npm run prototype:video-style`、`npm run prototype:video-cards`、`npm run prototype:video-effects` 或 `npm run prototype:video-settings` 即可打开相应页面。预览脚本使用本机 Python HTTP 服务，无需安装 npm 依赖。

主题源码与构建流程尚未建立。
