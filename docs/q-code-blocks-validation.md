## 窄窗口与嵌套块

| 场景 | 结果 |
| --- | --- |
| 浅色 820px、640px 桌面视口 | 阅读视图的带语言、无语言、列表、引用和标注代码块均保有外框，复制按钮在框内；整篇笔记无横向溢出。 |
| 深色 640px 桌面视口 | 同样 5 个代码块的按钮均位于外框内；长行在自身代码区域横向滚动，正文无横向溢出。 |

已知差异：Obsidian 当前实时预览把合成笔记中引用内的围栏显示为行内代码，未生成 `HyperMD-codeblock` 行；阅读视图正常渲染为围栏代码块。CSS 片段不会重新解释 Markdown 结构。桌面窄视口由开发协议临时模拟，测试结束后已恢复原窗口尺寸和浅色外观。

## 行号决定与清理

阅读视图的代码内容没有逐行节点。实时预览插入 180 行合成代码后，CodeMirror 初次仅渲染 38 行；跳到后段时渲染 59 行，首个可见节点从第 129 行附近开始，也没有真实行号属性。纯 CSS 无法在两个视图中保持准确的逐块编号，因此最终使用统一的 14px 无数字检查栏。原型里的行数和折行切换控件也不在正式片段中。

验收结束后已删除合成笔记和临时截图，恢复原笔记、浅色默认主题、原窗口尺寸，并保持 Q 两个片段及 Style Settings 已启用。
